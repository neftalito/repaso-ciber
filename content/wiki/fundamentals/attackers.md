## Criterio de clasificación

La clase relaciona perfiles de atacantes con motivaciones frecuentes. La clasificación sirve para pensar qué objetivos podría perseguir una operación, no para identificar a una persona a partir de un solo indicio.

| Perfil presentado | Motivaciones destacadas |
| --- | --- |
| Script kiddies | Curiosidad o reconocimiento personal |
| Cibercriminales | Beneficio económico |
| Hacktivistas | Objetivos ideológicos |
| Actores de Estado | Espionaje o sabotaje |
| Insiders | Venganza o beneficio económico desde una posición interna |

## Ejemplo y límites

Un empleado con acceso autorizado puede usarlo de forma indebida: la posición interna no garantiza un comportamiento legítimo. A la inversa, una interrupción de servicio no permite atribuir automáticamente el hecho a un hacktivista; actores distintos pueden utilizar técnicas semejantes.

:::question ¿Se puede deducir la identidad del atacante solo por el tipo de ataque?
No. Técnica, motivación e identidad son dimensiones distintas. Una atribución necesita evidencias propias y no se sostiene únicamente en esta tabla de perfiles.
:::
